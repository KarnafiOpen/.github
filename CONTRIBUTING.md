### How to contribute code safely:
1. **Open an issue first:** Discuss your proposed changes with us before writing code
2. **Sign the CLA:** Before we can review or merge any pull request, you must sign our [CLA](CLA.md)
3. **No third party code:** Any code you submit must be 100% written by you. Do not copy paste code from other open source projects (even MIT or Apache projects) into your pull request, as this violates our clean copyright rule

<br>

**Pull Requests submitted without a signed CLA or containing third party code will be closed immediately without review.**
